# 🦸 Marvel Hero Explorer

**Discover. Explore. Become a Hero.**

An interactive, single-page Marvel fan website where you can explore your favorite superheroes, compare their power stats, test your knowledge with a quiz, browse iconic movies, and visit famous locations from the Marvel Universe.

🔗 **Live Demo:** [https://krishnamagrawal05.github.io/marvel---website/](https://krishnamagrawal05.github.io/marvel---website/)

---

## ✨ Features

- **🏠 Hero Landing Section** – A bold intro with a call-to-action to start exploring.
- **🦾 Meet the Heroes** – Cards for Iron Man, Spider-Man, Thor, and Captain America. Click a card to open a detail panel.
- **📊 Power Stats** – View each hero's Strength, Speed, Intelligence, Durability, and Combat ratings.
- **⚔️ Hero Comparison** – Pick any two heroes and compare them side by side.
- **🧠 Marvel Quiz** – Multiple-choice questions with Next and Restart controls.
- **🎬 Marvel Movies** – Movie cards with release year, genre, rating, a short description, and a trailer link.
- **🌌 Marvel Universe Map** – Explore locations like New York, Wakanda, Asgard, Kamar-Taj, and Knowhere.
- **🌗 Light / Dark Mode** – Toggle between themes.
- **📱 Responsive Design** – Works on desktop, tablet, and mobile, with a hamburger menu on smaller screens.
- **⬆️ Back to Top** button for easy navigation.

---

## 🛠️ Tech Stack

- **HTML5** – Structure and content
- **CSS3** – Styling, layout, animations, and theming
- **JavaScript (Vanilla)** – Interactivity (hero details, comparison, quiz, theme toggle, map)

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/krishnamagrawal05/marvel---website.git
   ```
2. **Navigate into the folder**
   ```bash
   cd marvel---website
   ```
3. **Open the site**
   Double-click `index.html`, or run a local server:
   ```bash
   npx serve
   ```

---

## 🎮 How to Use

1. Click **Explore Heroes** or use the navigation bar to jump to a section.
2. Select a hero card to view their details and power stats.
3. Go to **Compare**, choose two heroes, and hit **Compare**.
4. Take the **Quiz** and see how well you know the Marvel Universe.
5. Browse the **Movies** section and watch trailers.
6. Click a location in the **Universe Map** to learn more about it.
7. Use the ☀️ / 🌙 button to switch between light and dark mode.
