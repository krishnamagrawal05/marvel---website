# 🦸 Marvel Hero Explorer

A responsive and interactive Marvel-themed web application built using HTML, CSS, and JavaScript.

The Marvel Hero Explorer allows users to explore popular Marvel heroes, view their abilities and power statistics, compare heroes, take a quiz, and explore Marvel movies.

## 🌐 Live Demo

🚀 **Live Website:**  
https://krishnamagrawal05.github.io/marvel---website/

## 📸 Features

### 🦸 Hero Explorer
- Explore popular Marvel heroes
- View hero descriptions and real names
- Interactive hero cards
- Hero power statistics

### 🔍 Hero Search
- Search heroes instantly
- Filter heroes based on their names

### ⚔️ Hero Comparison
- Compare two Marvel heroes
- Compare their abilities and statistics
- View real names and power levels

### 🧠 Marvel Quiz
- Interactive Marvel quiz
- Multiple questions
- Automatic score calculation
- Instant feedback

### 🎬 Marvel Movies
- Explore selected Marvel movies
- Movie information
- Watch trailer buttons

### 🌙 Dark / Light Mode
- Switch between dark and light themes
- Improved viewing experience

### 📱 Responsive Design
- Desktop-friendly layout
- Mobile-friendly interface
- Hamburger navigation menu

### ✨ Interactive Effects
- 3D hero card tilt effect
- Custom 3D cursor
- Smooth cursor trail
- Hover animations
- Loading animation
- Hero sound effects

### ⌨️ Keyboard Navigation
- Navigate hero cards using the keyboard
- Supports Enter and Space keys
